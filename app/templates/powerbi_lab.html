Laboratoire Power BI

Construisez un rapport interactif sur un jeu de ventes de démonstration, puis écrivez et testez vos mesures DAX. Toutes les mesures s'évaluent selon le contexte de filtre des segments, comme dans Power BI.

Table Ventes ( lignes) : colonnes Date, Annee, Mois, Ville, Produit, Canal, Client, Quantite, Prix, Montant

Ajouter un visuel

Cliquez sur une barre, un point ou une part pour filtrer les autres visuels (filtrage croisé) ; cliquez à nouveau pour annuler.

Nouvelle mesure

Fonctions : SUM, AVERAGE, MIN, MAX, COUNT, COUNTROWS, DISTINCTCOUNT, DIVIDE, CALCULATE, ALL, REMOVEFILTERS, SUMX, AVERAGEX, IF, ROUND, ABS, VAR/RETURN. Opérateurs : + - * / = <> < > <= >= && ||. Les noms de colonnes n'ont pas d'accent : Ventes[Quantite].
